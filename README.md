# قیمت‌شناس — نسخهٔ اپ موبایل

نسخهٔ مستقل وب برای نمایش و تست بازی. تمام سورس JavaScript، CSS، تصاویر و فونت‌ها در همین مخزن است. بیلد یا نصب پکیج لازم نیست.

## انتشار در GitHub Pages

۱. محتوای فایل ZIP را استخراج کنید. فایل `index.html` و پوشه‌های `src`، `play`، `styles`، `fonts` و `assets` باید در ریشهٔ ریپو قرار بگیرند؛ خود ZIP یا پوشهٔ حاوی همهٔ فایل‌ها را آپلود نکنید.
۲. در ریپو، Add file → Upload files را انتخاب کنید، همهٔ فایل‌ها و پوشه‌ها را بکشید و Commit changes را بزنید.
۳. Settings → Pages → Build and deployment → Source را روی Deploy from a branch تنظیم کنید.
۴. Branch را main و پوشه را / (root) انتخاب کنید و Save را بزنید.
۵. پس از پایان انتشار، این آدرس فعال می‌شود: https://amasn-a.github.io/gheimat-shenas-mobile/

لینک اشتراک‌گذاری و QR با همین آدرس تنظیم شده‌اند. لینک سایت در ChatGPT همچنان مستقل است و تغییرات آن به‌صورت خودکار به این ریپو منتقل نمی‌شود.

## اجرای محلی

در این پوشه `python -m http.server 8080` را اجرا کنید و http://localhost:8080 را باز کنید. باز کردن مستقیم index.html از روی دیسک برای ماژول‌های JavaScript مناسب نیست.

## محدودیت نسخه

این نسخه نمایشی است. فایل play/server.js بک‌اند را در مرورگر شبیه‌سازی می‌کند. رکورد، پرداخت و جایزهٔ واقعی سمت سرور در این بسته پیاده‌سازی نشده‌اند؛ برای عرضهٔ واقعی باید به سرویس‌های اصلی متصل شود.

## بررسی‌های موجود

اسکریپت‌های scripts/check-*.mjs را با Node.js اجرا کنید. این بررسی‌ها به وابستگی خارجی نیاز ندارند. سوابق نسخهٔ مبدا در docs/SOURCE-NOTES.md نگهداری شده‌اند.
