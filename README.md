# قیمت‌شناس
نسخهٔ عمومی بازی مقایسهٔ قیمت، با ورود مستقیم و بدون پنل ادمین یا صفحهٔ انتخاب حالت تست.
اولین شروع بازی، تمرین رایگان را نمایش می‌دهد. امتیاز، نشان و ۳ شانس روزانه در همین مرورگر نگه داشته می‌شود.

## جوایز سناریوی B
فقط بالاترین چک‌پوینت در پایان هر دست: ۵ تا ۹ پاسخ کد پلاس نمایشی، ۱۰ تا ۱۴ پاسخ ۳ دیجی‌کوین، ۱۵ تا ۱۹ پاسخ ۵ دیجی‌کوین و ۲۰ یا بیشتر کارت طلای نمایشی ۱۰۰ هزار تومانی. جایزه در هر دست مستقل است و رکورد پاداش اضافه ندارد.
این نسخه پرداخت یا جایزهٔ واقعی ندارد؛ کدها نمایشی‌اند و داده‌ها محلی هستند.

## انتشار
GitHub Pages از شاخهٔ main و مسیر ریشه اجرا می‌شود. index.html و پوشه‌های assets، fonts، play، src و styles باید در ریشه باشند.

## ماک موبایل با مرجع دیجی‌کالا و دیجی‌کوین
- `digikala/`: خانهٔ نمایشی با لوگو، تصاویر سرویس‌ها، بنر کمپین و شگفت‌انگیزهای واقعی مرجع. آیکون دیجی‌کوین به هاب می‌رود.
- `digicoin/`: تم سبزـآبی، دارایی، تب مأموریت/تاریخچه، جایزهٔ روزانه، بنر قیمت‌شناس، ردیف‌های مأموریت و پرسش‌های متداول.
- مرجع هاب: https://www.digikala.com/superapp/digicoin/ ؛ پس از ورود مشاهده و ساختار و رنگ‌ها از صفحه گرفته شد. این یک بازچینی موبایل از مرجع مشاهده‌شده است؛ مقایسهٔ یک‌به‌یک با اسکرین‌شات واقعی اپ موبایل هنوز انجام نشده.
- هیچ شماره، آدرس، موجودی واقعی، سابقهٔ شخصی یا اطلاعات ورود در فایل‌ها قرار ندارد. همهٔ تصاویر مورد استفاده محلی‌اند. موجودی و تاریخچه فقط از اطلاعات نسخهٔ نمایشی بازی در مرورگر خوانده می‌شوند.
- بخش جایزهٔ روزانهٔ هاب صرفاً اطلاعات حضور بازی را نمایش می‌دهد و هیچ جایزهٔ مستقلی ایجاد نمی‌کند. منطق سناریوی B و بازی اصلی تغییر نکرده است.
- ریشه همچنان بازی است و لینک‌های قبلی معتبرند؛ بازگشت از خانهٔ بازی به همان هاب ورودی می‌رسد.
