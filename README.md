# قیمت‌شناس
نسخهٔ عمومی بازی مقایسهٔ قیمت، با ورود مستقیم و بدون پنل ادمین یا صفحهٔ انتخاب حالت تست.
اولین شروع بازی، تمرین رایگان را نمایش می‌دهد. امتیاز، نشان و ۳ شانس روزانه در همین مرورگر نگه داشته می‌شود.

## جوایز سناریوی B
فقط بالاترین چک‌پوینت در پایان هر دست: ۵ تا ۹ پاسخ کد پلاس نمایشی، ۱۰ تا ۱۴ پاسخ ۳ دیجی‌کوین، ۱۵ تا ۱۹ پاسخ ۵ دیجی‌کوین و ۲۰ یا بیشتر کارت طلای نمایشی ۱۰۰ هزار تومانی. جایزه در هر دست مستقل است و رکورد پاداش اضافه ندارد.
این نسخه پرداخت یا جایزهٔ واقعی ندارد؛ کدها نمایشی‌اند و داده‌ها محلی هستند.

## انتشار
GitHub Pages از شاخهٔ main و مسیر ریشه اجرا می‌شود. index.html و پوشه‌های assets، fonts، play، src و styles باید در ریشه باشند.

## ماک مسیر ورود از دیجی‌کالا و دیجی‌کوین
- `digikala/`: ماک خانهٔ دیجی‌کالا؛ بنر و آیکون دیجی‌کوین به هاب می‌رسند.
- `digicoin/`: ماک هاب دیجی‌کوین؛ بنر اختصاصی قیمت‌شناس به بازی اصلی در ریشه می‌رسد.
- ریشه همچنان بازی است؛ لینک‌های اشتراک قبلی حفظ شده‌اند. برگشت از خانهٔ بازی، به صفحهٔ هابی می‌رسد که از آن وارد شده‌ای.
- موجودی هاب فقط از دادهٔ محلی نسخهٔ نمایشی خوانده می‌شود و چیزی به حساب واقعی اضافه نمی‌کند. سایر سرویس‌ها و پیشنهادها نمایشی‌اند.
- ساختار و رنگ‌های عمومی دیجی‌کالا بررسی شده‌اند؛ مسیر عمومی `/digicoin/` در زمان بررسی ۴۰۴ بود. هاب، طرح پیشنهادی است و بازسازی دقیق صفحهٔ فعلی سرویس نیست.
